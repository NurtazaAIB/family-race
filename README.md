# 🏁 Семейная Гонка

Гонка стеклянных шариков с лицами членов семьи. Android-игра.

## Установка
Откройте на телефоне страницу **[Releases → последняя версия](https://github.com/NurtazaAIB/family-race/releases/latest)**, скачайте `FamilyRace.apk` и установите
(разрешите установку из этого источника, если телефон спросит).

## Игроки
* Положите фото в папку **Pictures/FamilyRace** — имя файла станет именем игрока (`Мама.jpg`, `Дедушка.png`).
* Или нажмите в игре **«＋ Добавить игрока»**, введите имя и выберите фото из галереи.
* Нажатие на игрока — включить/выключить участие, удержание — удалить.

## Как устроена гонка
* 6 этапов: Солнечная долина → Сказочный лес → Ледяной спуск → Конфетная страна → Ночной город → Финишный стадион.
* Длительность 5–6 минут (в настройках есть режимы ~1 и ~3 минуты).
* Победитель выбирается честным криптослучайным образом в начале заезда — у всех равные шансы.
* Шарики всё время идут плотной группой (отставание последнего — не больше 1–2 секунд), лидеры постоянно меняются.
* Таблица побед сохраняется на телефоне.

APK собирается автоматически GitHub Actions при каждом изменении в `main`.
